# 成片工坊｜口播视频自动包装工具

这个工具支持两类输入：已经剪好的口播成片，或带停顿的原始录制。默认会自动判断，也可手动指定。

## 最简单的使用方法

1. 双击 `开始使用.command`（`开始生成.command` 也可以）。
2. 浏览器会打开“成片工坊”操作台。
3. 拖入主视频，可选添加配图、标题和重点词。
4. 选择“自动判断”“保持原片”或“剪掉长停顿”。
5. 点击“开始生成成片方案”，在页面里查看进度和封面。
6. 打开视频预览，确认字幕、动效和封面后，再点击导出最终 MP4。

素材只在本机处理，操作台地址固定为 `http://127.0.0.1:5088`。

## 可选设置

这些设置都可以直接在操作台填写。标题留空时会从文件名和视频开头内容自动提取。

## 每次生成的产物

在 `output/` 中可以找到：

- `subtitles.srt`：字幕文件
- `transcript.txt` / `transcript.json`：逐字稿
- `motion-plan.json`：剪辑和图文动效时间表
- `cover-9x16.png` / `cover-3x4.png`：两套封面
- `publish-copy.md`：标题和发布文案草稿

Studio 预览确认后，运行 `npm run render -- --output output/final.mp4` 导出成片。
